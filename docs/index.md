## 说明

- 未登录时画布项目和“我的素材”保存在浏览器本地；登录且账号同步可用时，会同步保存到账号/云端。
- 创作模型统一由平台云端提供，供应商协议和密钥由管理员在服务端维护；用户不能自配模型 Key 或回退浏览器直连。历史个人配置不主动删除，但不参与调用。
- 登录账号的个人空间默认含 1 GiB 免费基础额度，后台可调整；钱包显示文件索引统计，充值与永久扩容采用管理员人工确认，尚未接入在线支付。
