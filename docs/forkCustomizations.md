## 更新检查

每次建立 `sync/upstream-日期` 分支时，先逐项核对功能索引。即使 Git 自动合并成功，也要检查涉及同一组件、状态、API、数据库或存储格式的语义变化。不得用删除二开功能或未分析的 `ours` / `theirs` 选择解决冲突。无法证明受保护行为仍成立时，暂停该更新并记录到 `forkMaintenance.md` 的同步日志。
