# 待测试

## 小盟视频工作台品牌

- 登录页、首页、画布列表、管理后台和浏览器标题应显示“小盟视频工作台”；首页输入框上方显示“小盟万能视频工作台”及英文副标题；新建项目及导出文件使用“小盟画布”名称。
- 顶部不再显示 GitHub 图标、官方版本号、原项目公告或“许可与源码”入口；直接访问 `/legal` 仍可打开许可与源码说明。
- 登录页不再显示“支持账号密码和 Linux.do 登录。”说明，原有登录方式仍可使用。
- 首页不再加载官方宣传轮播，也不应出现其外部推广跳转；创作输入区仍可使用。
- 访问不存在的路径仍显示 404 页面，但页面顶部不再出现 TokenDance 等推广公告。
- 旧浏览器中的画布、素材和偏好应继续可用；本次未改原有 IndexedDB/localStorage 键。

## 管理员手动调点

- 正常调点后确认用户余额和 `credit_logs` 同时更新；余额未改变时不新增流水。
- 负数余额应被拒绝；数据库写入流水失败时，余额应回滚。
- 上述余额与流水场景尚未实际验证。

## 内置模型价格

- 后台未填写价格时，普通用户调用相应内置模型应被拒绝，且上游不收到请求。
- 管理员明确填写 0 时应允许免费调用；填写正价时应扣除对应算力点并记录流水。
- 工作流 Agent 的系统渠道应遵守同一规则；用户自有本地渠道应保留原有行为。
