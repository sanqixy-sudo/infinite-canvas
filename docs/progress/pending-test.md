## 短剧制作计划与画布基础交互

- 入口为项目详情“短剧制作”。本轮新增账号制作计划、分集剧本/场次、角色/场景/道具/声音/风格资产与变体、镜头描述/对白/运镜/整数时长/资产关联、排序和规划状态。制作页“导出与备份”及项目详情提供完整项目ZIP，复用根项目和全部子画布、制作计划及真实媒体打包；制作页包含当前未保存草稿。Markdown用于清单，JSON仅包含计划字段与关联标识、不含画布或媒体，不能单独导入；完整恢复使用项目ZIP。
- 镜头放入画布生成说明、空分镜图、空视频和参考连线；已有完整镜头定位原节点，失效绑定须确认重建。资产同画布复用，跨画布复制节点引用而非上传新文件；空内容、失效、跨项目引用明确拒绝。创建节点不调用模型、不扣费，生成时继续按模型能力校验。
- 制作计划新增5张表与鉴权CRUD，完整文档revision CAS保存、事务内引用校验；P2/P3/P4另加的任务、合成和团队表见下文及数据库文档。画布先保存到账号，再保存计划；失败保留localforage草稿。草稿按账号/项目隔离，卸载/切号/跨项目旧请求不更新当前页。
- 项目资产缩略图按存储标识解析，图片读取失败显示占位；视频/声音不为缩略图下载整文件。镜头放入前恢复图片参考并检查账号和画布快照，读取失败点名素材，异步期间变更不覆盖。

## P2 拆镜、任务队列与镜头成本

实际源码变更：

- 剧本和镜头页可打开AI拆镜，选择平台文字模型、目标镜头数与协议，显示现有调用价；返回严格结构校验后的可编辑草案。逐镜勾选、改画面/对白/运镜/时长/场次/资产，确认后追加，不覆盖原镜头或自动生成素材。
- AI草案与制作草稿按账号/项目/分集用localforage保留。采用前校验当前剧本/资产上下文与稳定镜头ID，先写制作草稿再清除拆镜草案；重复点击不重复追加。中止网络请求不保证上游未执行，失败不自动付费重试。
- 新增production_task_records/links，历史独立于原短期任务；首次提交冻结归属，不把后来的镜头绑定追算到旧任务。列表按分集、运行/失败/待结算筛选与分页，隐藏页面停止轮询，失败显示旧快照状态。
- 队列与镜头成本切换；汇总由服务端针对当前分集全部已记录任务计算，独立于当前页/状态筛选。共享任务总额只计一次；明细不直接相加。预扣、扣费、退回、净额、最终结算及输入/输出Token区分展示，未知不当0。
- 普通任务明确0价也写真实0流水；图片/视频/逐镜配音使用带类型的关联ID，防同编号串账。关联生产账本的流水在通用保存/删除路径受保护；后台HTTP流水原已只读。
- P3逐镜配音的`production_voice_*`任务已接入持久历史。创建前核验当前账号的`workspaceId + shotId`，保存后冻结分集/镜头归属；费用按`audio:<任务ID>`的真实扣退流水计算，短期音频任务清理后历史与金额仍保留。配音显示独立类型和未知状态，不在网关重试入口重放；在镜头配音区恢复原ID或再次明确确认生成。
- 网关失败且已结算/释放时可单条或勾选本页批量重试，先报价确认预扣，再顺序提交。稳定requestId在请求前落地；刷新/超时恢复已受理任务，原任务有后继后禁止再分叉；异常停止余下批次。团队审批任务禁用直接/批量重试，显示回团队项目重新申请审批；撤销共享或清理短期任务后仍遵守此规则。普通非网关任务继续回画布确认参数后生成。
- 进程重启时普通无法确认的在途任务标未知，不当失败自动重发。此处理当前适用单API容器；网关已有独立持久轮询。历史仅覆盖功能启用后已保存绑定的任务，文字拆镜及未关联调用不算入镜头总额。

## P5 标准模型、多规格路由与定价

实际源码变更（集中自动检查通过并已部署，真实渠道验收仍待完成）：

- 中间件后台可创建、编辑、启停标准模型及多个真实规格。每个规格绑定真实渠道、上游模型ID和已实现协议，配置分辨率、比例、时长区间、参考场景、音频条件、素材上限和原价；条件重叠或无唯一匹配时拒绝保存/提交，不按优先级猜路由。
- 画布同步公开目录后，模型弹窗按真实分组展示标准名称、各规格支持数量、价格、徽标和备注。分辨率联动比例/时长/音频选项，参考素材变化会重新核对规格；连接数量与服务端提交均按实际规格校验。未配置的模型和价格不会自动开放。
- 支持Token总量、输入/输出不同价、按秒和按次；规格可分别配置有/无参考视频原价。画布后台按原价倍率或逐规格固定算力售价发布。Token仍只用任务返回的真实用量；按秒明确采用请求时长或响应中的整数时长，按次仅成功任务计1次。缺实际数量保持待核对，不换用另一种单位猜费用。
- 报价冻结规格ID、计费单位、数量来源、预扣数量和单价；提交重新核对报价与当前规则。新版本影响新任务，已受理任务保持原请求、路由、密钥及计费快照；相同requestId在报价失效或配置改变后仍优先恢复已有任务，不再次付费。
- 原四个Seedance特殊渠道及New API插件0.2.2继续固定720×1280、分别Token计费。新增同协议模型/规格通过后台保存和画布同步发布，无需重建容器；新协议适配器仍需开发和部署，不宣称任意供应商接口自动兼容。
- 当前适配器为：原四模型专用插件协议、Seedance原生任务协议、NewToken第三方`/v1/videos`的`reference_*`按秒协议。第三方按秒每个上游ID对应单一720p或1080p、4～15秒和文档比例；不等同于官方`extra_*`混合计费接口。其未开放的水印/音频开关不伪装可调；音频按渠道实际输出设置固定条件。
- 生产历史增加实际计费秒/次的展示，保留Token分项为空与实际零的区别。新增唯一路由、配置冻结、各计费单位、缺用量与前端报价匹配的用例；没有执行真实付费生成。
