## 管理员手动调点

- 正常调点后确认用户余额和 `credit_logs` 同时更新；余额未改变时不新增流水。
- 负数余额应被拒绝；数据库写入流水失败时，余额应回滚。
- 上述余额与流水场景尚未实际验证。

## 内置模型价格

- 后台未填写价格时，普通用户调用相应内置模型应被拒绝，且上游不收到请求。
- 管理员明确填写 0 时应允许免费调用；填写正价时应扣除对应算力点并记录流水。
- 工作流 Agent 的系统渠道应遵守同一规则；用户自有本地渠道应保留原有行为。
- 只有后台明确勾选开放、渠道已启用且配置了 API Key 的模型才应出现在公开清单并允许调用；取消勾选后，即使渠道仍有该模型也应拒绝请求。
- 后台应拒绝重复模型、负数、非有限数字或超过两位小数的单价；重新排序渠道后，未输入新 Key 的渠道不得继承其他渠道的 Key。
- 视频按请求时长向上取整计点；显式传入非法时长应在上游调用前拒绝。视频任务保存失败、普通 AI 调用失败及工作流 Agent 失败时，检查返还流水与余额。

## R2 配置流程

- 新建 S3/R2 配置应默认停用，可先保存未填写密钥的草稿；启用前应要求完整配置与合法 Endpoint。
- 容量统计应只使用已保存的配置，不应把页面未保存的 Bucket、Endpoint 或密钥写入后台设置；达到容量上限时应停用该配置。
- 清空已保存密钥的输入框再保存时，应保留同一配置的原密钥；改成另一个配置时不得继承原密钥。
- 尚无 R2 测试资源，上传、读取、删除、容量统计和素材自动同步仍需真实存储桶联调。
