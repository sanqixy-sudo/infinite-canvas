- 总 Token、输入／输出不同价、预扣及多退少补的计算和任务用量校验保持不变。后续多分组、多规格不在此插件版本开放。
- 新版离线用例未执行，真实 New API 导入、上游输出尺寸及收费任务仍待验证；更新插件本身不代表线上中间件能力已同步。
